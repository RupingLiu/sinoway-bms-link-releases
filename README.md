This is the official release repository for **Sinoway BMS Mate**. It provides Android install packages, update manifests, and release notes only; it is not the application source repository.

### Current Release

| Platform | Version | Primary download | Backup download |

- **Android 7.0+**: a signed release APK and internal update delivery are currently available.

### What it provides

- Cloud-based device status, cell data, parameters, location, and trajectory views.
- Cloud-sourced alarms and device fault status, using the platform's actual alarm data.
- Landscape historical curves with cell information and MOS status.
- Live BMS Bluetooth diagnostics, subject to account permissions and device protocol capabilities.

### Download and update

Download the latest APK from [Gitee Releases](https://gitee.com/rupingliu/sinoway-bms-link-releases/releases), or use [GitHub Releases](https://github.com/RupingLiu/sinoway-bms-link-releases/releases) as the backup mirror. Internal-distribution builds can download updates from **Profile > Check for updates**; Android system confirmation is always required before installation.

### Security

- Download APKs only from Release assets in this repository.
- Verify the SHA-256 value supplied with the release when needed.
- Release packages must not contain production secrets, customer data, map-service tokens, or device-sensitive credentials.
