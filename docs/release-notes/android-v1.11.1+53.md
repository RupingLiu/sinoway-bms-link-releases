# Sinoway BMS Link Android 1.11.1+53

## 简体中文

- 优化总览、设备、地图、告警、蓝牙、我的和设备详情页的运维界面视觉密度，让列表、筛选、卡片和工具入口更紧凑统一。

- Refined the operational UI density across Overview, Devices, Map, Alarms, Bluetooth, Profile, and Device Detail so lists, filters, cards, and tool entry points feel more compact and consistent.

- Improved spacing, dividers, and readability across Device Detail, Parameters, Controls, and map-related cards for faster scanning on phones.
