# Sinoway BMS Link Android 1.11.0+52

## 简体中文

- 新增云端设备轨迹回放地图页，支持按日期范围加载轨迹、播放/暂停、拖动进度和切换播放速度。
- 优化轨迹回放界面，减少控制面板占用空间，提升播放流畅度，并使用车辆图标显示当前播放位置。
- 设备详情状态页精简定位与轨迹内容，仅保留最近定位摘要和地图/地图回放入口。
- 总览页面新增设备分组下拉，地图页面设备选择器同步为设备页同款分组树。
- 总览、设备、地图和告警页面在进入详情或切换页面后保留分组、状态、等级和搜索筛选。

## 繁體中文

- 新增雲端設備軌跡回放地圖頁，支援依日期範圍載入軌跡、播放/暫停、拖曳進度和切換播放速度。
- 優化軌跡回放介面，減少控制面板占用空間，提升播放流暢度，並使用車輛圖示顯示目前播放位置。
- 設備詳情狀態頁精簡定位與軌跡內容，只保留最近定位摘要和地圖/地圖回放入口。
- 總覽頁面新增設備分組下拉，地圖頁面設備選擇器同步為設備頁同款分組樹。
- 總覽、設備、地圖和告警頁面在進入詳情或切換頁面後保留分組、狀態、等級和搜尋篩選。

## English

- Added a cloud trajectory playback map page with date-range loading, play/pause, progress scrubbing, and playback speed controls.
- Optimized the trajectory playback UI to reduce panel height, improve playback smoothness, and show the current playback point with a vehicle marker.
- Simplified the Device Detail status page location section to keep only the latest location summary and Map/Map Playback entry points.
- Added a device group selector to Overview, and aligned the Map device selector with the same grouped tree used by Devices.
- Overview, Devices, Map, and Alarms now keep group, status, severity, and search filters when entering details or switching pages.
