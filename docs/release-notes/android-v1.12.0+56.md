# Sinoway BMS Mate 1.12.0+56

## 简体中文

- 新增“历史曲线”入口：直接在 APP 中横屏展示云平台原有历史曲线页面，保留云端曲线能力和设备上下文。
- 云端登录会话失效时，曲线页会明确提示重新登录 APP 账号，避免用户停留在无数据或无法理解的页面。
- 优化设备目录、最新定位和统计数据的聚合与按账号缓存加载，降低首屏等待和重复接口请求；刷新期间保留可用数据。
- 地图页改为紧凑设备摘要：设备名称、在线/SOC、经纬度、速度、电压和四项操作在同一张卡内清晰分层。
- “历史曲线”与“轨迹”保留独立文字和不同图标：时钟历史图标表示曲线历史，节点路径图标表示定位轨迹。

## 繁體中文

- 新增「歷史曲線」入口：直接在 APP 中橫向顯示雲端原有歷史曲線頁面，保留雲端曲線能力和裝置上下文。
- 雲端登入工作階段失效時，曲線頁會明確提示重新登入 APP 帳號，避免使用者停留在無資料或難以理解的頁面。
- 最佳化裝置目錄、最新定位和統計資料的聚合與依帳號快取載入，降低首屏等待和重複介面請求；重新整理期間保留可用資料。
- 地圖頁改為緊湊裝置摘要：裝置名稱、在線/SOC、經緯度、速度、電壓和四項操作在同一張卡片中清晰分層。
- 「歷史曲線」與「軌跡」保留獨立文字和不同圖示：時鐘歷史圖示代表曲線歷史，節點路徑圖示代表定位軌跡。

## English

- Added a Historical Curves entry that opens the existing cloud historical-curve page in landscape while keeping the selected device context.
- When the cloud sign-in session expires, the curve page clearly asks the user to sign in to the app again instead of leaving an unexplained empty state.
- Improved aggregated, per-account cached loading for the device catalog, latest location, and statistics to reduce initial waiting and repeated API requests while retaining usable data during refresh.
- Reworked the Map card into a compact device summary with device identity, online/SOC state, coordinates, speed, voltage, and four clearly grouped actions.
- Historical Curves and Track now use distinct labels and icons: a history clock for curves and a node path for location tracks.
