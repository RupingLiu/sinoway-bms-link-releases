# Sinoway BMS Link Android 1.7.0+36

## 简体中文

新增 WiFi 自动下载更新包。internal 构建启动后会等待手机连接 WiFi，再自动检查并下载可用 APK；蜂窝网络下不会自动下载，用户仍可在“我的 > 检查更新”里手动检查或下载。

安装仍由用户手动确认。自动下载完成后，用户需要点击“安装更新包”，再确认 Android 系统安装器。

## 繁體中文

新增 WiFi 自動下載更新包。internal 建置啟動後會等待手機連接 WiFi，再自動檢查並下載可用 APK；行動網路下不會自動下載，使用者仍可在「我的 > 檢查更新」中手動檢查或下載。

安裝仍由使用者手動確認。自動下載完成後，使用者需要點擊「安裝更新包」，再確認 Android 系統安裝器。

## English

Added automatic update package download on Wi-Fi. Internal builds now wait until the phone is connected to Wi-Fi before automatically checking for and downloading an available APK. Automatic download does not run on cellular networks, while users can still manually check or download from Profile > Check for updates.

Installation still requires user confirmation. After automatic download completes, the user must tap Install update and confirm the Android system installer.
