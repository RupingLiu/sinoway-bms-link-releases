# Sinoway BMS Link Android 1.9.0+49

## 简体中文

- App 启动后会持续周期检查新版本，不再只依赖打开 App 时的一次性检查。
- 检测到新版本且当前已连接 WiFi 时，自动下载更新包。
- 更新包下载完成后，App 顶部会显示“发现新版本可以更新”的提示，点击提示或“安装更新包”即可启动系统安装器。
- 进入“我的/检查更新”时，已下载或需要安装授权的更新包也会保留安装入口，用户可从个人页面继续安装。
- 下载完成后会等待用户安装，不会因为周期检查重复下载同一个更新包。

## 繁體中文

- App 啟動後會持續週期檢查新版本，不再只依賴開啟 App 時的一次性檢查。
- 偵測到新版本且目前已連接 WiFi 時，自動下載更新包。
- 更新包下載完成後，App 頂部會顯示「發現新版本可以更新」提示，點擊提示或「安裝更新包」即可啟動系統安裝器。
- 進入「我的/檢查更新」時，已下載或需要安裝授權的更新包也會保留安裝入口，使用者可從個人頁面繼續安裝。
- 下載完成後會等待使用者安裝，不會因為週期檢查重複下載同一個更新包。

## English

- After startup, the app now checks for new versions periodically instead of relying on a single one-time check when opened.
- When a newer version is available and the device is on Wi-Fi, the APK is downloaded automatically.
- After the package is downloaded, a top-of-app prompt appears; tapping the prompt or Install update opens the system installer.
- The Profile update card also keeps the install action available when the package has already been downloaded or install permission is required.
- Once downloaded, the app waits for the user to install and avoids repeatedly downloading the same update package during periodic checks.
