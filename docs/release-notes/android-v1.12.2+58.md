# Sinoway BMS Mate 1.12.2+58

## 简体中文

- 统一总览、设备、告警和地图页面的设备与分组统计口径；在线、离线、总数及分组下拉中的数值使用同一统计对象，地图的已定位数量与设备目录数量明确区分。
- 设备故障状态仅依据云平台的未处理告警。告警尚未同步完成时显示为未知，不再把本地单体压差等计算结果判定为故障或正常。
- 告警列表保留云平台原始故障名称，并按电流、电池、电压、温度、通信和开关等类别显示不同图标；点击告警可进入对应设备详情。
- 优化历史曲线横屏嵌入体验：调整整体缩放、返回按钮、工具区和单体信息的可见性，并补全充电、放电、加热 MOS 状态展示。
- 蓝牙告警页明确标注“来源：BMS 蓝牙实时读取”。

## 繁體中文

- 統一總覽、裝置、告警和地圖頁面的裝置與群組統計口徑；在線、離線、總數及群組下拉中的數值使用同一統計物件，地圖的已定位數量與裝置目錄數量明確區分。
- 裝置故障狀態僅依據雲端平台的未處理告警。告警尚未同步完成時顯示為未知，不再把本機單體壓差等計算結果判定為故障或正常。
- 告警清單保留雲端平台原始故障名稱，並按電流、電池、電壓、溫度、通訊和開關等類別顯示不同圖示；點選告警可進入對應裝置詳情。
- 最佳化歷史曲線橫向嵌入體驗：調整整體縮放、返回按鈕、工具區和單體資訊的可見性，並補齊充電、放電、加熱 MOS 狀態顯示。
- 藍牙告警頁明確標註「來源：BMS 藍牙即時讀取」。

## English

- Unified device and group statistics across Overview, Devices, Alarms, and Map. Online, offline, total, and group-selector values now use one shared statistics model; located-map counts are kept distinct from catalog counts.
- Device fault status now comes only from unresolved cloud alarms. Devices remain unknown while alarms are still syncing; local cell-voltage-delta calculations no longer classify a device as faulty or normal.
- Alarm rows retain the original cloud fault name and use distinct icons for current, battery, voltage, temperature, communication, and switch categories. Selecting an alarm opens its matching device details.
- Improved the embedded landscape history-curve view by adjusting page scale and the visibility of the back control, tool area, cell details, and charge/discharge/heating MOS states.
- Bluetooth alarm pages now explicitly state that their source is a live BMS Bluetooth read.
