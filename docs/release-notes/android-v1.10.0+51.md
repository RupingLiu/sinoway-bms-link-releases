# Sinoway BMS Link Android 1.10.0+51

## 简体中文

- 总览、设备、地图和告警页面新增统一设备搜索入口。
- 搜索会同时匹配设备号码、设备名称、铁塔编码和主板型号，用户不需要先选择搜索方式。
- 搜索窗口增加可输入内容提示，进入搜索模式后在列表上方显示明确的“搜索模式”提示和清除入口。
- 告警页面新增设备搜索，并将分组下拉菜单同步为设备页面同款树形分组选择器。
- 告警页面和设备页面的分组默认值统一为当前账号的顶层分组，不再默认显示“全部分组”。
- 优化总览页面筛选/搜索按钮布局，使“全部/在线/离线/搜索”更紧凑一致。

## 繁體中文

- 總覽、設備、地圖和告警頁面新增統一設備搜尋入口。
- 搜尋會同時匹配設備號碼、設備名稱、鐵塔編碼和主板型號，使用者不需要先選擇搜尋方式。
- 搜尋視窗增加可輸入內容提示，進入搜尋模式後在列表上方顯示明確的「搜尋模式」提示和清除入口。
- 告警頁面新增設備搜尋，並將分組下拉選單同步為設備頁面同款樹形分組選擇器。
- 告警頁面和設備頁面的分組預設值統一為目前帳號的頂層分組，不再預設顯示「全部分組」。
- 優化總覽頁面篩選/搜尋按鈕布局，使「全部/在線/離線/搜尋」更緊湊一致。

## English

- Added a unified device search entry across Overview, Devices, Map, and Alarms.
- Search now matches device number, device name, tower code, and mainboard model at the same time, so users no longer need to choose a search field first.
- The search sheet now explains accepted search terms, and active search mode shows a clear banner with a one-tap clear action above the list.
- Alarms now support device search and use the same tree-style group selector as the Devices page.
- Alarm and Device group selectors now default to the current account's top-level group instead of showing "All groups" by default.
- Improved the Overview filter/search button layout so All, Online, Offline, and Search feel more compact and consistent.
